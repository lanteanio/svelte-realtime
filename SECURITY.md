# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/lanteanio/svelte-realtime/security/advisories/new).
This repository has private vulnerability reporting enabled. Do not put exploit
instructions, tokens, cookies, personal data, or private deployment details in a
public issue or pull request.

Include the affected package and version, Node and adapter versions, deployment
mode, impact, a minimal reproduction, and any mitigation you have tested.
Maintainers coordinate investigation and disclosure in the private report.
There is no guaranteed response time or supported-version backport commitment;
use the latest published prerelease when checking whether a problem persists.

Ordinary defects belong in the public issue tracker using its bug report form.
